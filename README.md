# Red Wine Quality: Explanatory Regression Analysis

**Module 2 . Sprint 3: Regression** | Turing College . Data Science Programme

Explanatory OLS regression: identify which physicochemical properties of Portuguese *Vinho Verde* red wines are most strongly associated with perceived quality.

---

## Project Goal

Given 11 physicochemical measurements, build an explanatory regression model that quantifies which variables are most strongly associated with expert wine quality ratings. The aim is interpretability, not prediction accuracy.

**Primary metric:** Adjusted R-squared (variance explained by the model).
**Secondary metrics:** BIC (parsimony), hold-out RMSE and MAE.

> This is an *explanatory* model, not a predictive one. Causal language is deliberately avoided throughout.

---

| Features | 10 continuous physicochemical measurements |
| Target | `quality` (ordinal 0-10, median of at least 3 expert ratings) |
| Class imbalance | 82% of wines scored 5 or 6; scores 3 and 8 have fewer than 20 samples each |

## Notebook Flow

The notebook follows a strict leakage-safe pipeline. The test set is sealed at Section 4 and not touched until Section 13.

| Section | Title | Key content |
|---|---|---|
| 1 | Imports and Setup | Dependencies, paths, global settings |
| 2 | Dataset Description | Source, variable glossary, key caveats |
| 3 | Initial Data Assessment | Shape, dtypes, missings, outlier screen, duplicate analysis, free SO2 redundancy test |
| 4 | Train / Test Split | Stratified 80/20 split with visual confirmation |
| 5 | Hypotheses | Stated and justified before looking at model results |
| 6 | Exploratory Data Analysis | Distributions, boxplots by quality, Pearson and Spearman correlations, heatmap, violin deep-dive |
| 7 | Variable Transformations | log1p with semi-elasticity rationale |
| 8 | Multicollinearity Check | VIF before and after removing density |
| 9 | Model Fitting | Full OLS model (9 predictors) via statsmodels formula API |
| 10 | Model Interpretation | Coefficient plot, styled table, semi-elasticity interpretation, standardized betas |
| 11 | Stepwise Backward Elimination | One variable removed per step, tracked with adj-R-sq, AIC, BIC |
| 12 | Residual Diagnostics | Residuals vs fitted, Q-Q, scale-location, Jarque-Bera |
| 13 | Hold-out Evaluation | RMSE, MAE, R-squared, actual vs predicted |
| 14 | Hypothesis Answers | Formal verdict for both hypotheses |
| 15 | Limitations and Improvements | Ordinal target discussion, future directions |

## Results

| Metric | Full model (9) | Reduced model (6) |
|---|---|---|
| Train adjusted R-squared | ~0.35 | ~0.35 |
| Hold-out R-squared | ~0.41 | ~0.41 |
| Hold-out RMSE | ~0.65 | ~0.65 |
| Hold-out MAE | ~0.50 | ~0.50 |

The reduced model (6 predictors) is adopted because it is more parsimonious, has a lower BIC, and the shared coefficients remain stable after removing the non-significant terms.

**Hypothesis outcomes:**

1. **Primary (volatile acidity):** H0 rejected. Negative association is statistically significant (95% CI excludes zero).
2. **Secondary (alcohol):** H0 rejected. Positive association is statistically significant (95% CI excludes zero).

---

## Key Findings

- **Alcohol** has the largest positive standardized effect on quality ratings.
- **Volatile acidity** has the largest negative standardized effect. Each additional 1 g/dm3 is associated with nearly a full one-point drop in quality.
- **Sulphates** show a positive association, consistent with their antimicrobial preservative role.
- Both Pearson and Spearman correlations were computed to account for the ordinal nature of the target. The two measures agree closely, confirming the linear signal is not driven by outliers.
- 240 duplicate rows (15%) were statistically tested before removal to confirm they were not a biased subset.
- `free_sulfur_dioxide` was excluded based on a three-test redundancy framework (correlation, VIF, regression p-value).

## Reproducibility

| Mechanism | Detail |
|---|---|
| Fixed seed | `RANDOM_SEED = 42` passed to all stochastic steps |
| Stratified split | Target distribution preserved in train and test |
| Leakage-safe pipeline | All EDA and transformations on training set only |
| Stepwise elimination | One variable removed per step, not all at once |
